# Blow — 기획서 (접수양식 02 섹션 원문)

> 이 파일이 DOCX 양식 02 섹션의 단일 원본이다. `## N.` 아래 내용이 양식의 N번 박스에 그대로 들어간다.
> 표기: `**제목**` 줄 = 굵게, `- ` = 글머리표, 빈 줄 = 줄 띄움. 성명·연락처·소속은 쓰지 않는다(양식 규칙).

## 1. 앱 한 줄 소개

**도로를 감상하세요. 현대가 당신의 DJ가 되어드릴게요.**
Blow는 지금 달리는 도로와 그 순간의 날씨에 맞춰, 운전자가 손대지 않아도 음악을 불러오는 차량용 음악 앱입니다. 길은 내비가, 음악은 Blow가. (Blow = 음악을 '불러오다' + 창밖 풍경처럼 음악이 '불어오다')

## 2. 기획 배경

**주목한 순간**
해안도로에 들어서 바다가 펼쳐지는 순간, 비 오는 밤 한강변을 달리는 퇴근길. 창밖 풍경은 계속 바뀌는데 차 안의 음악은 그대로입니다.

**차 안 음악은 이미 일상입니다**
- 차량에서 음악 서비스를 이용한 사람은 1년 새 59% 늘었고, 그 70%가 출퇴근 세대인 30·40대입니다. (KT지니뮤직, 2024 연간 데이터)
- 국내 연구에서도 차 안에서 하고 싶은 활동 상위에 '음악감상'이 꼽혔습니다. (2017, 한국콘텐츠진흥원 지원 연구) 해외에서는 응답자의 66%가 차 안에서 음악을 듣습니다. (IFPI)

**그런데 지금의 경험은 불편합니다**
- 선곡 피로: 매번 고르기 귀찮아 같은 플레이리스트만 반복합니다.
- 조작 위험: 분위기에 맞는 곡을 찾으려면 운전 중에 화면을 만져야 합니다. 인포테인먼트 조작은 평균 40초 동안 운전자의 주의를 빼앗고, 도로에서 2초만 눈을 떼도 사고 위험은 2배가 됩니다. (AAA 교통안전재단, 2017)
- 풍경과의 단절: 지금 이 길, 이 날씨에 어울리는 곡을 그 순간에 맞춰 틀기란 사실상 불가능합니다.

**왜 차량이어야 하는가**
스마트폰 음악 앱은 내가 무엇을 좋아하는지는 알지만, 지금 어디를 달리고 있는지는 모릅니다. 차량은 위치·경로·목적지를 아는 유일한 공간이고, Pleos Connect는 이 맥락을 앱에 열어 줍니다. Blow는 이 맥락을 음악으로 바꿉니다.

## 3. 앱 주요 기능 및 차량 특화 요소

**① 도로 DJ — 진입하는 순간 음악이 불어온다**
- 음악 도로에 진입하면 곡이 서서히 커지며 시작되고, DJ 멘트가 화면에 뜹니다. 예) "지금부터 올림픽대로 반포 구간. 창밖에 비가 내리네요. 이 길엔 이 노래."
- GPS가 튀어도 곡이 끊기지 않도록 진입·이탈을 여러 번 연속 확인한 뒤 판정합니다.

**② 낮·밤 × 날씨 = 8가지 무드**
- 1차로 낮/밤, 2차로 맑음·흐림·비·눈을 나눠, 같은 도로도 8가지 다른 곡을 갖습니다.
- 날씨는 실시간 기상 데이터로만 판단합니다. 차량 센서로 추정하지 않습니다. (와이퍼는 맑은 날에도 유리를 닦을 때 켜지므로 '비'의 근거가 될 수 없습니다.)

**③ 빈 도로가 없는 기본 선곡 (3단계)**
- 1단계 명소 도로(해안도로·한강변·드라이브 코스): 큐레이터가 8무드 곡을 직접 지정
- 2단계 도로 유형(해안·산길·도심·고속도로·터널·교량): 유형별 규칙으로 자동 배정
- 3단계 그 밖의 모든 위치: 지역 기본 곡
→ 어느 길을 달려도 Blow가 정해 둔 곡이 있습니다.

**④ 내 도로 (커스터마이징)**
- 도로마다, 8무드 칸마다 내 곡을 지정하면 기본 선곡보다 항상 먼저 재생됩니다. 예) 출근길 한강 구간의 '맑은 낮' = 내가 가장 좋아하는 곡
- 안전 설계: 편집은 정차 중에만 허용하고, 주행 중에는 "방금 지난 도로에 이 곡 저장" 한 번 누르기만 가능합니다.

**⑤ 속도와 상관없이 끊기지 않는 음악**
- 도로는 노래를 켜는 '스위치'입니다. 구간을 빨리 지나도 곡은 끝까지 들려줍니다.
- 끊김 없는 전환(오토믹스 방식): 곡이 재생 중일 때 다음 음악 도로에 진입하면, 지금 곡과 다음 곡을 자연스럽게 섞어 넘깁니다.
- 속도 맞춤 진입: 내비 경로와 현재 속도로 도로 도착 시간을 계산해 진입 순간에 곡이 시작되게 맞추고, 짧게 지나가는 구간은 곡의 하이라이트(후렴)부터 재생합니다.

**⑥ 내비와 함께 달리는 음악 앱**
- Blow는 음악 앱입니다. 운전자는 평소처럼 Pleos 내비를 쓰고, Blow는 켜지는 순간부터 뒤에서 내비의 위치·경로를 따라갑니다.
- 내비에서 길안내를 시작하면 "Blow로 음악 들으실래요?" 제안이 뜹니다. 한 번 누르면 그 길의 음악 도로마다 노래가 준비됩니다. (내비 길안내 시작 신호 수신 — 구현 완료)
- 지도는 Blow가 따로 그리지 않고, 버튼 하나로 실제 Pleos 내비 지도를 띄웁니다. (구현 완료)
- 음악 도로를 누르면 Pleos 내비가 그곳까지 길안내를 시작하고, 음악 도로를 잇는 드라이브 코스를 추천합니다. (길안내 구현 완료)

**⑦ 음원 서비스 연동**
- Blow는 "언제·무엇을" 고르는 DJ이고, 재생은 사용자가 이미 쓰는 음원 서비스가 맡습니다. 안드로이드 표준 미디어 연동으로 차량에 설치된 음원 앱에 재생을 요청합니다.
- 시연 버전은 Apple Music 공식 30초 미리듣기(하이라이트)로 실제 대중가요를 재생하고 앨범 아트를 보여 줍니다. 음원 파일은 앱에 넣지 않습니다.

**차량 특화 요약**
- 위치·경로 맥락: 내비 경로를 미리 읽어 도로 진입 전에 곡을 준비
- 화면 조작 0회: 시동 후 Blow를 켜 두기만 하면 선곡 완료
- 내비와 공존: 내비 안내 음성이 나오면 음악 볼륨 자동 감소
- 주의 분산 최소화: 큰 글씨, 한눈에 읽히는 화면, 주행 중 편집 차단

## 4. 주요 사용 시나리오

**시나리오 A — 비 오는 밤, 퇴근길 직장인**
- 퇴근길 시동. Pleos 내비에 '집'으로 길안내를 건다.
- 내비 화면 위로 "Blow로 음악 들으실래요?" — 한 번 누르면 끝. 이후 운전자는 아무것도 하지 않는다.
- 화면에 "1.2km 뒤, 올림픽대로 반포 구간" — 곧 노래가 나온다는 기대감.
- 진입 순간 DJ 멘트 "창밖에 비가 내리네요. 이 길엔 이 노래." 와 함께 비 오는 밤의 곡이 불어온다.
- 다음 음악 도로에 들어서면 곡이 자연스럽게 다음 곡으로 넘어간다.
→ 화면 조작 0회. 매일 같은 퇴근길이 날씨와 시간마다 다른 음악으로 바뀐다.

**시나리오 B — 주말 해안 드라이브 (커플·친구)**
- 목적지를 설정하면 Blow가 경로 위 음악 도로를 미리 알려 준다.
- '음악 드라이브 코스'를 골라 해안도로를 지난다.
- 바다가 보이는 순간 곡의 하이라이트가 시작된다 — 드라이브의 명장면이 된다.
- 휴게소에 정차해 "이 도로, 내 노래로" 저장 → 다음 방문 때 그 곡이 기다린다.

**시나리오 C — 내 도로 만들기 (정차 중)**
- 주차 후 Blow에서 출근길 한강 구간을 고른다.
- 8무드 중 '맑은 낮' 칸에는 신나는 곡, '비 오는 밤' 칸에는 잔잔한 곡을 지정한다.
- 다음 날부터 그 길은 나만의 출근 BGM이 된다.

## 5. 개발 계획

**현재 구현 상태 (Pleos Connect Emulator 2.1.0에서 동작 확인)**
- Kotlin + Jetpack Compose, 차량 가로 화면(2560×1440) 전용 UI
- 현재 위치·길안내 시작 신호: NaviHelper SDK (앱을 켜면 자동 연동)
- 실제 내비 지도 호출: NaviHelper requestNavigationScreen
- 음악 도로 판정 엔진: 도로 중심선 + 폭으로 구간을 정의하고 진입·이탈을 연속 확인 (단위 테스트 통과)
- 실시간 날씨 → 낮/밤 × 맑음·흐림·비·눈 8무드 변환 (프로토타입 노르웨이 기상청 공개 API, 상용화 시 기상청 API)
- 음원: Apple Music 공식 30초 미리듣기 스트리밍 + 앨범 아트 (음원 파일 미포함)
- 재생: Media3 — 페이드인/아웃, 두 곡을 겹쳐 넘기는 끊김 없는 전환, 도로를 벗어나도 곡은 끝까지, 내비 안내 시 볼륨 자동 감소(오디오 포커스)
- 길안내: NaviHelper requestRoute 로 음악 도로까지 안내
- 데모 주행 모드: 실제 주행 없이 진입 장면 재현

**Pleos Connect SDK 사용 계획**
- NaviHelper (사용 중): 현재 위치, 길안내 시작 신호("Blow로 음악 들으실래요?"), 실제 내비 지도 호출, 음악 도로 길안내 — 상용화 시 경로 정보로 진입 시점 미리 계산
- Vehicle SDK (적용 예정): 차속으로 도착 시간 계산 보정, 주행 상태 연계(정차 중 편집)
- TextToSpeech (출시 시 적용): DJ 멘트 음성 출력 — 현재는 화면 표시
- SpeechToText (출시 시 적용): "이 노래 저장", "다음 곡" 음성 명령
- FusedLocation (출시 시 적용): 더 정밀한 차량 위치

**일정**
- ~11/15 (1차): 기획서 + 동작 프로토타입 APK + GitHub
- ~12/3 (2차 PT): 음원 서비스 연동, 내 도로 편집, 속도 맞춤 진입, 음악 도로 데이터 확장
- 수상 시: Pleos App Market 출시 준비

## 6. 기대효과 및 발전 가능성

**사용자 가치**
- 선곡 0, 조작 0 — 운전에만 집중하면서 매 순간 어울리는 음악
- 익숙한 출퇴근길이 날씨마다 달라지는 경험 → "운전이 기다려지는" 일상

**타깃 고객**
- 출퇴근 직장인: 반복되는 길의 지루함, 선곡 귀찮음 → 같은 길도 날씨·시간마다 다른 곡 + 내 도로
- 드라이브·여행족: 드라이브의 '순간'을 특별하게 → 명소 도로 큐레이션 + 드라이브 코스

**예상 MAU**
- 현대자동차그룹은 2030년까지 현대·기아·제네시스 약 2,000만 대에 Pleos Connect 탑재를 목표로 합니다.
- 산식: 탑재 차량 2,000만 대 × 앱 설치율 1% × 월간 활성률 50% = 약 10만 MAU (보수적 가정)

**Retention (재사용) 근거**
- 출퇴근은 매일 반복되는 경로 → 같은 도로에서도 8가지 무드가 돌아가며 새로움 유지
- 내 도로를 쌓을수록 나만의 지도가 생겨 이탈 비용이 커짐
- 시동을 걸면 켜 두기만 하는 앱 → 매 주행이 곧 사용

**수익 모델**
- 대표 모델 — 스폰서 도로: 지자체·관광지의 "공식 드라이브 사운드트랙" (예: ○○ 해안도로 공식 플레이리스트). 지역은 관광 홍보, 운전자는 특별한 드라이브, 현대차는 차별화된 경험을 얻습니다.
- 음원 서비스 제휴: 연동 서비스로의 청취 유입
- 아티스트 프로모션 도로: 신곡을 특정 드라이브 코스에 배치
- 내 도로 공유: 사용자가 만든 도로 플레이리스트를 공유 → 콘텐츠가 사용자와 함께 늘어나는 구조

**확장**
- 현대·기아·제네시스 전 차종, 해외 Pleos 탑재 지역으로 확대
- 계절·축제·이벤트 한정 도로, 지역 라디오·관광 안내와 결합
